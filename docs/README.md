# Docs

## RFCs

- `rfc-process.md` — how Blocky uses RFCs for major architecture and semantics changes
- `rfc-001-initial-design.md` — initial blockchain and REPL architecture; implemented and partially superseded by RFC-002
- `rfc-002-smart-contracts.md` — world state, Wasm contracts, SDK, gas metering, and receipts; implemented with some follow-up work still open

## Notes

RFCs in this repository are lightweight internal design records.

- Before implementation, they describe the proposed direction.
- After implementation, the code is authoritative.
- When implementation intentionally differs, the RFC should record the deviation and its status.
